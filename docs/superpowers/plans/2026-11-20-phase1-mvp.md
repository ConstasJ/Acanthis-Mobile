# Acanthis Mobile Phase 1 (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `acanthis-mobile`（M0 脚手架基础上）一次性完成 Phase 1（MVP）全部核心功能：服务器配置、书架与 `/v1/sync/state` 跨端双向同步、动态发现页（首页/榜单/分类/搜索）、小说详情与分卷目录、以及支持插图全屏缩放和下一章预取的上下滚动阅读器。

**Architecture:** 采用 AGP 9 双模块（`:composeApp` + `:androidApp`）与 Room 5 表单一真相源（`bookshelf_items`、`reading_progress`、`dirty_sync_queue`、`novel_cache`、`chapter_cache`）；独立的 `SyncCoordinator` 负责对齐 `apps/web` 的 LWW 合并与 2 秒防抖推送；页面采用 `@Serializable` Navigation Compose 路由 + 每页独立 `ViewModel` + `StateFlow`，并由 Koin 统一注入。

**Tech Stack:** Kotlin `2.3.21`, AGP `9.1.1`, Gradle `9.3.1`, Compose Multiplatform `1.11.1`, Material 3 `1.9.0`, Ktor `3.4.3`, Room KMP `2.8.5` + `sqlite-bundled` `2.7.1`, KSP `2.3.14`, DataStore `1.2.1`, Coil 3 `3.4.0`, Ksoup `0.2.6`, Koin `4.1.1`, JetBrains Navigation Compose `2.9.2`.

**Spec:** `docs/superpowers/specs/2026-11-20-phase1-mvp-design.md`

## Global Constraints

- 工具链版本严格沿用 `gradle/libs.versions.toml` 锁定值（AGP `9.1.1`、Kotlin `2.3.21`、CMP `1.11.1`、Material 3 `1.9.0`、Room `2.8.5`、KSP `2.3.14`）；Compose 依赖必须使用显式 Maven 坐标，禁用已废弃的 `compose.*` 插件快捷访问器。
- `:androidApp` 禁止应用 `org.jetbrains.kotlin.android`；`:composeApp` 的 `commonMain` 严禁导入任何 `android.*` 或 `java.*`。
- 环境变量在 Windows PowerShell 执行 Gradle 前需确保 `JAVA_HOME = "C:\Program Files\Zulu\zulu-21"`（无末尾反斜杠）与 `ANDROID_HOME = "D:\Android\Sdk"`。
- `chapter_cache` **不做自动 LRU 淘汰**，除非用户在设置页手动清理，否则永久保留；保留 `source` 字段（默认 `"auto"`）供 Phase 2 扩展。
- 所有封面、分卷封面与插图 URL 均须经 `rebaseMediaUrlWithBase(rawUrl, apiBaseUrl)` 重写。
- 每个 Task 结束必须通过 `.\gradlew.bat :composeApp:testAndroidHostTest --stacktrace`（及涉及 UI/装配时 `.\gradlew.bat :androidApp:assembleDebug --stacktrace`），并按 Conventional Commits（中文描述 + 详细 body）本地原子化提交，严禁 `git push`。

## Review Focus

1. **推送在途本地二次修改**：`POST /v1/sync/state` 请求发出后、返回前，本地同一条书架或阅读进度再次更新（`updatedAt` 变大）；推送返回后严禁误删该脏队列条目（由 Task 3 `SyncCoordinatorTest` 钉死）。
2. **游标被 POST 污染**：`POST /v1/sync/state` 返回的 `serverTime` 绝不能写入 `lastSyncCursor`，游标只能由 `GET /v1/sync/state` 的 `cursor` 推进（由 Task 3 `SyncCoordinatorTest` 钉死）。
3. **切换服务器地址残留旧游标与旧域名图片**：用户修改 `apiBaseUrl` 后必须自动重置 `lastSyncCursor = 0L`，且所有封面/插图 URL 自动 rebase 到新地址（由 Task 2 `ServerConfigStore` 逻辑与 Task 4 `ExploreRepositoryTest` 钉死）。
4. **上游 `503 + Retry-After` 与搜索 5 秒节流**：遇到 Cloudflare 拦截/429 需准确解析 `Retry-After` 秒数，5 秒内重复搜索需拦截并给出剩余冷却秒数（由 Task 1 `AcanthisApiClientTest` 与 Task 4 `ExploreRepositoryTest` 钉死）。
5. **断网/空卷/首尾章边界**：断网打开已缓存详情页时后台刷新失败须保留本地目录不覆盖；空分卷与第一章/最后一章切换上下章不得越界崩溃（由 Task 4 `ReaderRepositoryTest` 与 Task 9 `ChapterNavigatorTest` 钉死）。
